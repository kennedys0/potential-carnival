# TELEGRAM FLOW MAP

## 1. Onboarding
`/start` -> Welcome Message -> `[Open Dashboard]` `[Wallet Setup]` `[Help]`

## 2. Dashboard
Home Screen -> Bot Status, PnL Summary, Open Positions Count -> `[Portfolio]` `[Wallet]` `[Scanner]` `[Settings]`

## 3. Portfolio
Portfolio Overview -> Position List (Scannable Cards) -> Click Position -> Position Detail View -> `[Close Position]` `[Refresh]` `[Back]`

## 4. Wallet
Wallet Summary (Balances) -> `[Withdraw]` `[Export Key]` -> Withdraw Flow -> Choose Amount -> Confirm Transfer -> Status Update

## 5. Scanner
`/scan CA` -> Scan Summary -> `[Buy]` `[Refresh]` `[Chart]` -> Trade Lifecycle UI

## 6. Settings
Settings Menu -> Mode Toggle, Risk Presets, Defaults -> Edit Modal/Inline updates.
